# Acendia.us — Service Page Keyword Briefs
**Source:** Semrush US database, live search volume/CPC/KD as of Aug 2026
**Purpose:** On-page SEO targeting for Claude Code to implement across live service pages
**Scope:** Title tags, H1s, meta descriptions, body copy, FAQ sections, internal linking

---

## How to use this file (for Claude Code)

For each page below:
1. Set `<title>` to include the **Primary Keyword**, brand name, and stay under 60 characters.
2. Set the H1 to a natural-language variant of the Primary Keyword (don't force exact-match if it reads robotic).
3. Use **Secondary Keywords** in H2s and body copy — don't keyword-stuff, one concept per section.
4. Build an FAQ section (schema: FAQPage) from the **Question Keywords** — these are real "People Also Ask"-style queries.
5. **Long-Tail/Local variants** belong in supporting content or internal links to location pages (`/locations/[state]/[city]/`), not forced onto the core service page.
6. Update `meta-description` to naturally include the Primary Keyword within the first 120 characters.
